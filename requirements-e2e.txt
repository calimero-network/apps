# The merobox toolchain for every app's e2e, pinned in ONE place.
#
# ⚠️ Pinning merobox alone pins NOTHING. `calimero-client-py` is a transitive
# dependency that tracks core master, so an unpinned install silently picks up
# whatever landed there today: 0.6.27 broke `create_namespace`, 0.6.26 broke
# `join_namespace`. A commit that changes nothing can turn the e2e red, and
# merobox's Rich renderer hides the real error. Eight of the nine app repos had
# it unpinned.
#
# Install from PyPI, not the apt repo at calimero-network.github.io/merobox —
# that no longer serves a Release file and 404s at install, which reads like a
# contract break rather than a dead mirror.
#
# Cache ~/.cache/pip in CI: calimero-client-py ships an sdist only, so every
# uncached job compiles a Rust wheel (~70s measured).
