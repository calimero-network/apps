# Mero Drive — Phase A: dep bump + alias→metadata migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bump mero-drive to `@calimero-network/mero-js@^2.1.0` + `@calimero-network/mero-react@^2.3.0` and fix all the resulting breakage from core PR #2338 (group `alias` → `MetadataRecord`), with **no behavior change** — just compile-green + tests-green against the new SDKs. Also retire the now-redundant `registry::set_folder_alias` mirror (folder names come from core group metadata's `name` on list rows).

**Architecture:** Mechanical migration. `alias` fields on `Namespace`/`GroupMember`/`SubgroupEntry` become `name`; `GroupInfo.alias` becomes `GroupInfo.metadata?.name`; `groupAlias` becomes `groupName`; `useSetGroupAlias`/`setGroupAlias` become `useSetGroupMetadata`/`setGroupMetadata({ name })`. The `registry` WASM `set_folder_alias` mirror is removed (and its callers stop calling it); the registry still keeps `set_color`, parent, context-binding, sort-order. This is Phase A of a 5-phase feature (B: open/restricted folders, C: capability realignment + `permissions` module, D: sync loader, E: merobox e2e) — each subsequent phase gets its own plan.

**Tech Stack:** TypeScript/React/Vite + Vitest (`mero-drive/app`); Rust WASM with `calimero-sdk` (`mero-drive/logic/crates/{registry,docs,types}`); pnpm.

**Workspace:** isolated git worktree at `/Users/beast/Developer/Calimero/mero-drive--open-restricted`, branch `feat/open-restricted-folders-permissions`, based off `refactor/frontend-battleships-alignment`. The dep bump in `app/package.json` (`@calimero-network/mero-js` → `^2.1.0`, `@calimero-network/mero-react` → `^2.3.0`) + `pnpm install` is **already done** — Task 1 just commits it. All commands below run from `app/` unless noted.

**Reference:** the design spec is at `docs/superpowers/specs/2026-05-12-open-restricted-folders-permissions-design.md` (gitignored, local-only) — §2 covers the #2338 contract this migration tracks.
